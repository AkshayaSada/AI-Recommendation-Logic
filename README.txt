PROJECT NAME:
AI Recommendation Logic

OBJECTIVE: 
To create a recommendation system that suggests
career paths based on user skills.

TOOLS USED:
- Python
- VS Code

FEATURES:
- User skill input
- Matching logic
- Recommendation engine
- Top 3 recommendations

WORKING:
The user enters skills. The program compares
those skills with predefined job roles and
calculates a match score. The highest scoring
roles are recommended.

CONCLUSION:
This project demonstrates recommendation
systems, pattern matching and AI-based
decision support.
